SOFTWARE REQUIREMENTS SPECIFICATION
PRIVATE INDIAN JEWELLERY SHOP MANAGEMENT SYSTEM
VERSION 1.0

======================================================================
1. INTRODUCTION
======================================================================

1.1 Purpose
This document specifies the requirements for a private Indian jewellery
shop management web application. The system manages sales, inventory,
purchases, customers, suppliers, accounts, job work, repairs, old gold
exchange, and reporting for a private jewellery business.

1.2 Scope
The application is an internal business tool, NOT a public e-commerce
storefront. It is used by the shop owner, manager, and staff.

1.3 User Roles
- OWNER: Full access to all features including financial data, settings,
  backup, audit logs, user management, and sensitive operations.
- MANAGER: Business operations access. Configurable financial access.
  Cannot access backup, security settings, or user management.
- STAFF: Operational access only. Cannot see profit, purchase costs,
  owner withdrawals, sensitive financial reports, backup, or security.

4. JEWELLERY CALCULATION RULES
======================================================================

4.1 Net Metal Weight
= Gross Weight - Stone Weight - Other Material Weight

4.2 Fine Gold Weight
= Net Metal Weight × (Purity / 24)
(For gold items)

4.3 Metal Value
= Net Metal Weight × Rate per gram

4.4 Making Charge
= Configurable per item (fixed amount or percentage)

4.5 Wastage
= Configurable percentage of metal value or fixed amount

4.6 Stone Charges
= Fixed amount per item

4.7 Taxable Value
= Metal Value + Making + Wastage + Stone Charges + Other Charges - Discount

4.8 Final Value
= Taxable Value + Applicable Tax

4.9 Old Gold Exchange Value
= Fine Gold Weight × Buy Rate - Deductions

4.10 Important: All calculation values (rate, purity, weight) used at
transaction time must be stored with the transaction. Changing today's
rate must NOT alter historical transactions.
